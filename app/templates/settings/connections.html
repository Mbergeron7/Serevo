Setup Guide

  1. Go to Google Cloud Console → Service Accounts
  2. Create a service account (or use an existing one)
  3. Create a JSON key and download it
  4. Enable the Google Sheets API and Google Drive API in your project
  5. Share each Google Sheet with the service account email (as Viewer)
  6. Paste the JSON key contents above
